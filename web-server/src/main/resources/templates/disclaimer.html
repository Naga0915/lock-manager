電子ロッカー利用規約

第1条（適用範囲および定義）

  1. 本規約は、〇〇株式会社（以下「弊社」といいます）が提供する電子ロッカー（以下「本サービス」）のすべての利用者（以下「利用者」といいます）に適用されます。
  2. 本規約における用語の定義は次のとおりとします。
    1. 会員：本規約に同意の上、弊社が定める手続を完了し、ロッカー利用の許可を受けた者。
    2. ロッカー：弊社が提供する保管用設備（電子制御式を含む）を指します。
    3. 利用期間：会員がロッカーの利用を許可された期間。
    4. 身分証明書：学生証、運転免許証、健康保険証、在留カード、マイナンバーカード等、弊社が認める本人確認書類。
    5. 重大な過失：通常要求される注意義務を著しく欠いた行為。
    6. 不可抗力：天災、戦争、疫病、政府の命令その他制御不能な事情。

第2条（会員制度）

  1. 本サービスは会員制とし、利用にあたっては本規約への同意および弊社所定の手続きを完了することを要します。

第3条（規約変更）

  1. 弊社は、本規約を変更する場合があります。変更時は、事前または速やかに登録メールアドレスに通知します。
  2. 会員は、通知後にサービスを継続利用した場合、変更後の規約に同意したものとみなします。

第4条（入会資格）

  1. 以下のいずれかに該当する者は、会員としての入会を認めません。また、入会後に判明した場合は直ちに会員資格を取消すことがあります。
    1. 本規約違反歴がある者、または遵守できない者
    2. 申込時に虚偽情報を提供した者
    3. 他人に迷惑・損害を与えた、またはそのおそれのある者
    4. 反社会的勢力に属する、または関係する者
    5. 自己の責任において安全な利用が困難と弊社が判断する者（例：泥酔状態、重度の精神疾患）
    6. 会員資格の取消歴がある者
    7. その他弊社が適切でないと判断する者
  2. 弊社は、必要に応じて身分証明書の提示を求めることがあり、提示がない場合は入会を拒否することがあります。

第5条（利用時間）

  1. 利用時間は 7:00～22:00 とします。
  2. 業務上の都合または不測の事態により、事前通知なく利用制限・中断することがあります。

第6条（収容禁止物）

以下の物品は収容できません：

  • 現金、有価証券、パスポート、重要書類（契約書、権利証、登記簿謄本、申請書類等）
  • 宝石、カメラ等の高級品（5,000円超）
  • 遺体・遺骨
  • 爆発物・揮発性ガス・危険物
  • 銃器・刀剣等の犯罪に使用されうるもの
  • 臭気・不潔・腐敗・変質物、汚損及び毀損のおそれのあるもの
  • 15kg以上の物、動物、その他弊社が不適切と判断するもの

第7条（収容品の放置）

  1. 利用期間終了後 1ヶ月間引取りがない場合、会員が権利を放棄したものとみなし、弊社は任意に処分できます。処分にかかる費用を利用者に請求します。

第8条（異常利用への対応）

第6条違反またはその疑い（異臭、液体漏れ、異常音など）がある場合、以下の対応を無断で行うことがあります：

  1. 開扉
  2. 収容品の確認・処分
  3. 警察等への通報および情報提供

第9条（解約）

  1. 会員からの解約は、前月15日までに所定の手続きを完了するものとします。
  2. 以下の場合、弊社は即時に会員資格を取り消します：
    1. 第6条違反
    2. 施設・設備に重大な損害を与えた場合
    3. 公序良俗に反する行為
    4. その他弊社が適切でないと判断した者

第10条（賠償）

  1. 弊社が賠償責任を負うのは、故意または重大な過失による通常の損害に限り、上限は 5,000円 とします。
  2. 会員が他者に損害を与えた場合は、自己の責任と負担において賠償するものとします。
  3. 以下の場合、弊社は一切の責任を負いません：
    1. 第6条違反による損害
    2. 会員の過失（誤操作、鍵紛失など）
    3. 第三者とのトラブル
    4. 不可抗力（天災・停電・通信障害等）
    5. 官公署等による押収等
    6. 不正アクセスや犯罪行為による損害
    7. 収容期間経過後の品物損失
    8. 使用方法の逸脱
    9. 本人確認不備、虚偽申告
    10. サービス中断による直接・間接損害

第11条（個人情報の取扱い）

  1. 弊社は、会員の個人情報を以下の目的のため、弊社の定める個人情報保護方針に基づき適正に収集・利用・管理します。
    1. サービスの登録および提供
    2. 連絡およびサポートの提供
    3. 利用状況の分析、改善
    4. 法令対応、安全確保
  2. 会員の同意がない限り、個人情報を第三者に提供しません。ただし、以下の場合を除きます：
    1. 法令・裁判所命令等による場合
    2. 緊急性があり、本人同意取得が困難な場合
    3. 守秘契約を締結している業務委託先に提供する場合
  3. 弊社は、アクセス制限や暗号化など合理的な安全管理措置を講じます。
  4. 利用目的達成後、または保存義務が消滅した際には、速やかに適切な方法で廃棄・消去します。
  5. 会員は自己の情報について、開示・訂正・削除・利用停止等を請求することができます。
