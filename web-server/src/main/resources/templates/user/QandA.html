電子錠ロッカー Q&A

基本的なこと

Q1. 電子錠ロッカーとは何ですか？
A1. 学生証などの認証方式で開閉できる電子制御式のロッカーです。鍵の貸し借りが不要で、スマートに施錠・解錠ができます。
Q2. どんな人が利用できますか？
A2. 本学の学生・教職員で、学内の利用条件を満たしている方が利用できます。
Q3. 利用は有料ですか？
A3. 基本的に無料で利用できますが、長期利用や特定の用途では別途料金がかかる場合があります。

利用料金・支払い

Q4. 利用料金の支払い方法は？
A4. 利用料金が発生する場合、支払い方法は現金のみとなります。詳細は登録時にご案内します。

登録・申し込みについて

Q5. 登録に必要なものは何ですか？
A5. 学籍番号・氏名・住所・電話番号・大学付与のメールアドレス（OECUメール）です。
Q6. どこから申し込めますか？
A6. 「登録方法ページ」に記載のメールひな形を参考に、必要事項を入力し管理者メールへ送信してください。
Q7. 登録結果はいつわかりますか？
A7. 申請後、当日から7日以内にOECUメールアドレス宛に結果をお送りします。
Q8. 申請内容に不備があった場合は？
A8. 内容に不備がある場合、確認や修正依頼のため、結果通知が遅れることがあります。

解錠・施錠について

Q9. どうやってロッカーを開け閉めしますか？
A9. ログイン後、マイページ上部の「解錠・施錠」ボタンから、自分のロッカーを選んで操作してください。
Q10. 何度でも解錠・施錠できますか？
A10. はい、使用中であれば期間内は何度でも可能です。
Q11. ロッカーが開かないときは？
A11. まずはマイページで操作を再試行してください。改善しない場合は管理者までご連絡ください。

利用中・利用後のこと

Q12. ロッカーの利用期間はどれくらいですか？
A12. 期間は登録時にお知らせします。延長が必要な場合は管理者までご相談ください。
Q13. 荷物を入れたまま期限が過ぎたらどうなりますか？
A13. 期限を過ぎると管理者がロッカーを開錠し、中身を保管します。一定期間後は処分されることがあります。
Q14. ロッカーを使わなくなったらどうすればいいですか？
A14. 必要に応じて、マイページから解約申請を行うか、管理者へ連絡してください。

セキュリティ・トラブル

Q15. 荷物の盗難や破損があった場合は？
A15. 貴重品の保管は避けてください。万一の盗難や破損については、自己責任となります。
Q16. ログインできない場合は？
A16. 学内ネットワークやOECUアカウントの設定を確認し、問題が解決しない場合は情報システム担当窓口または管理者へご連絡ください。

お問い合わせ

Q17. 連絡先はどこですか？
A17. 管理者メール（例：locker-admin@〇〇.ac.jp）へご連絡ください。
