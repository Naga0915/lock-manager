電子錠ロッカー登録方法

本施設では、学生証認証式の電子錠ロッカーを導入しています。ロッカーの利用を希望する方は、以下の手順で登録を行ってください。

登録に必要な情報

  • 学籍番号
  • 氏名
  • 住所
  • 電話番号
  • OECUメールアドレス（大学付与のメール）

登録の流れ

  1. 下記の登録依頼メールひな形に必要事項を記入し、管理者メールアドレスへ送信してください。
  2. メール送信後、入力内容は管理者に送信されます。
  3. 管理者が確認後、当日から7日以内に、登録されたOECUメールアドレス宛に結果をご連絡します。

注意事項

  • 入力情報に不備がある場合、確認に時間がかかることがあります。
  • 必ず大学のメールアドレスをご使用ください（例：***@oecu.jp）。
  • 個人情報は電子錠ロッカー管理業務以外には使用しません。

登録依頼メールひな形

下記のひな形をコピーして必要事項を入力し、管理者メールアドレスに送信してください。

件名：電子錠ロッカー利用申請

本文：
電子錠ロッカーの利用を希望します。
以下の通り、必要情報を提出します。

・学籍番号：○○○○○○
・氏名：○○○○
・住所：〒○○○-○○○○ ○○市○○町○丁目○番地
・電話番号：090-○○○○-○○○○
・OECUメールアドレス：○○○○@oecu.jp

よろしくお願いいたします。

お問い合わせ先

管理者メール：locker-admin@〇〇.ac.jp

登録完了後

登録完了後、管理者よりロッカー番号・利用開始日などの詳細をOECUメールアドレス宛にお知らせします。

安全かつ便利にご利用いただくため、正確な情報を入力し、登録完了メールを大切に保管してください。
