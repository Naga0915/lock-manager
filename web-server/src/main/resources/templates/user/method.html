予約方法及び使用方法

予約方法

ヘッダーの「予約」ボタンをクリックしてください。

→

カレンダーから予約したい日付を選択します。

→

予約状況を確認し、空きがあれば利用したい開始時刻と終了時刻を入力します。
利用するロッカー番号を「Lock ID」に入力し、「予約送信」をクリックして予約完了です。

使用方法

ヘッダーの「解錠・施錠する」ボタンをクリックしてください。

→

上記の図中にある表の黒くなっているボタンは、
予約中のロッカーが施錠中なら赤色、
解錠中なら緑色になります。

→

操作したいロッカーをクリックし、
「lock」「unlock」を選択することで
ロッカーの開閉操作ができます。
予約時間中は何度でも操作可能です。
